Features

Everything sits next to your code.

Coverage panel

Every folder and file with its percentage and the change since your last run.

Honest totals

Files no test imports are listed at 0% and counted, so the total isn't inflated.

Editor highlights

Covered and uncovered lines in the gutter, plus a jump to the next uncovered line.

Check Test Strength

Finds lines your tests run but never actually check.

Create Test File

A ready _test.dart with a stub for every public class and method.

Risk radar & insights

Riskiest files, a coverage map and a history of every run.

Honest totals

The files nobody tested still count.

flutter test --coverage skips files that no test imports, so they never lower your number. Dartboard adds them back at 0%.

# flutter test --coverage lcov.info 38 files 86.0% # Dartboard tested 38 files not tested 7 files 72.4%
Check Test Strength

Green doesn't always mean tested.

Dartboard makes tiny temporary changes to covered lines and re-runs the tests. If nothing fails, that line is a weak spot. Your file is always restored.

a > b → a <= b caught x == y → x != y caught isAdmin && on → isAdmin || on missed total + tax → total - tax missed
Get started

Your first report in a minute.

Works with any Flutter or Dart project. Monorepos and generated files are handled for you.

  1. Install Dartboard

    From the VS Code Marketplace, or search “Dartboard” in Extensions.

  2. Open your project

    Dartboard starts when it finds a pubspec.yaml.

  3. Click ▶ in the Dartboard panel

    It runs flutter test --coverage and fills in the panel.
