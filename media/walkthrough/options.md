# Make it yours

Click the **filter** button in the panel for options:

- **Group by** folders, app layers (UI · State · Data · Utils), or a flat list
- **Sort** least covered first, most covered first, or by name
- **Only files changed on this branch**: perfect before opening a PR (needs git)
- **Coverage goal**: shows a progress bar and how many lines you still need

In the `⋯` menu:

- **Share Coverage**: copy a Markdown summary for your PR, or save a README badge

Need this tour again? Click **?** in the panel.
