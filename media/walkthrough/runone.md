# Run just one file's tests

Hover over any file or folder in the panel and click **▶**. Only the related tests run (for `lib/auth/login.dart` that's `test/auth/login_test.dart`), and the result is merged into your existing report. Much faster than running everything.

## Live coverage

Turn on **Live coverage on save** (panel `⋯` menu or Options). Every time you save a Dart file, its test re-runs in the background and the green and red lines update.
