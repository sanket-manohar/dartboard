# Test your screens

Above every `testWidgets` you get three buttons:

| Button | What it does |
| --- | --- |
| **📱 Screen sizes** | Runs the test on a small phone, a phone, a tablet, large text and dark mode. Overflows show as a grid in the Tests tab. |
| **👁 Accessibility** | Checks tap target sizes, button labels and text contrast, and lists each problem with the widget to fix. |
| **🎞 Filmstrip** | Records every frame the test drew so you can scrub through it and see exactly where it went wrong. |

Above every function, **N cases to test** lists the branches, nulls, empty values and errors your tests haven't hit yet, and adds test stubs for the ones you pick.

Change the sizes in the `dartboard.screenMatrix` setting.
